# Blip AI - Official Releases

> **Official distribution channel for Blip AI desktop app**

This repository contains official releases of Blip AI. Your app automatically checks for updates from this repository.

## 📥 Download Latest Version

**[Download Blip AI →](https://github.com/abnsl0014/blipai-releases/releases/latest)**

### Installation Instructions

1. Download the DMG file from the [Releases page](https://github.com/abnsl0014/blipai-releases/releases)
2. Double-click the DMG file to open it
3. Drag **Blip AI.app** to your **Applications** folder
4. Launch Blip AI from Applications

## 🔄 Auto-Updates

Blip AI automatically checks for updates when you launch the app. When a new version is available:

1. A notification banner will appear at the top of the app
2. Click "Download Update" to download in the background
3. When ready, click "Restart & Install" to update

You can also manually check for updates:
- Go to **Settings** → Click "Check for Updates"
